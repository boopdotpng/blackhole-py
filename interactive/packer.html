How sure is this?

  • on hw confirmed on card 0 by tests/hw/test_contexts.py: cfg_ctx picks the context; Dest row offset (in rows) and the pack counters follow the context; edge masks and row-set mappings are shared.
  • Everything else follows the ISA doc's functional model (written for Wormhole) with the Blackhole changes it lists: L1 Y/Z/W strides in bytes (16B aligned), one packer.
  • inferred intf=0 (all interfaces) reads 4 consecutive Dest rows per PACR: that is how tt-llk's MOPs advance Y by 4. Not probed here.
  • Early format conversion is simplified to "round (or truncate) to the context's In_data_format". Packer L1 accumulate for BFP outputs is not modeled.
  • Not modeled: PACR auto-context (CtxtCtrl), OvrdThreadId/ADC selection, packer reading from L1 (Source_interface_selection), strided Dest access mode, timing.
