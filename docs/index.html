MOP

opcode 0x01MOP expander (frontend)

Expand a macro-op template. The thread's MOP expander replaces this one word with a looped sequence of instructions built from the 9 MOP_CFG words, emitting one instruction per cycle.

Encoding

31:240x0123template22:16loop_count15:0mask_lo
namebitsdescription
template230 mask-driven, 1 nested loop.
loop_count22:16Template 0: iterations minus 1.
mask_lo15:0Template 0: low 16 bits of the skip mask (the high 16 come from MOP_CFG). Template 1: keep 0.

MOP_CFG words

Per thread, MMIO at 0xFFB80000 (uint32_t[9], isa.MOP_CFG_WORDS), written by that thread's RISC. Write-only.

wordtemplate 0template 1
0unusedouter: outer count (10 bits)
1flags: bit 0 has_b, bit 1 has_a123inner: inner count (10 bits)
2bstart
3a0end0
4a1end1 (only if end0 is not NOP)
5a2loop0
6a3loop1 (NOP = no alternation)
7skip_alast_final: last inner instruction of the final outer pass
8skip_blast_other: last inner instruction of every other outer pass

Template 0: mask-driven

mask = (mop_cfg_hi << 16) | mask_lo        # mop_cfg_hi: set by MOP_CFG
for i in range(loop_count + 1):
  if not (mask >> i) & 1:                # bit clear: the "a" path
    emit(a0)
    if flags & 2: emit(a1); emit(a2); emit(a3)
    if flags & 1: emit(b)
  else:                                    # bit set: the "skip" path
    emit(skip_a)
    if flags & 1: emit(skip_b)

Template 1: nested loop

is_nop = lambda w: w >> 24 == 0x02            # only plain NOP, not SFPNOP / DMANOP
n_inner = inner * (1 if is_nop(loop1) else 2)  # loop1 present: alternate loop0, loop1, loop0, ...
for j in range(outer):
  if not is_nop(start): emit(start)
  op = loop0
  for i in range(n_inner):
    if i < n_inner - 1: emit(op)
    elif j < outer - 1: emit(last_other)        # word 8
    else:               emit(last_final)        # word 7
    op = loop1 if op is loop0 and not is_nop(loop1) else loop0
  if not is_nop(end0):
    emit(end0)
    if not is_nop(end1): emit(end1)

Example: outer=2, inner=3, loop1 = NOP, everything else set:

start loop0 loop0 last_other end0 end1   start loop0 loop0 last_final end0 end1

probed Word 7 (last_final) is emitted once, as the last inner instruction of the final outer pass; word 8 (last_other) ends every other outer pass. This matches tt-isa-documentation (Loop0Last).

Rules

rulewhy
Before rewriting MOP_CFG words, load from 0xFFE80008.The load returns once the expander is idle. The expander reads the words while it runs.
Template 1: don't use start = NOP with inner = 0.Hardware bug: the outer count comes out wrong.
Counts are 10 bits (template 1), 7 bits (template 0 loop_count).Higher bits are ignored.
A MOP followed by a non-MOP costs one idle cycle.Put a REPLAY of 2+ instructions in the template if every cycle matters.

REPLAY

opcode 0x04replay expander (frontend)

Record instructions into, or replay them from, the thread's 32-word replay buffer.

Encoding

31:240x0423:14start13:4length3:1execute0record

Arguments

namebitsdescription
start23:14First buffer slot.
length13:4Number of instructions to record or replay. 0 replays 64 (the buffer twice) probed.

Behaviour

  for i in range(length):
    w = next_incoming_word()
    buf[(start + i) % 32] = w
    if execute: emit(w)                # execute=0: store only

STALLWAIT

opcode 0xA2wait gate

Hold back selected instruction classes of this thread until selected conditions clear.

Encoding

31:240xA223:15stall14:0wait

Arguments

namebitsdescription
stall23:15isa.Stall mask: which classes of this thread's later instructions wait.
wait14:0isa.Wait mask: what they wait for. All selected conditions must clear.

Behaviour

while any(cond_active(c) for c in wait):   # all selected conditions must clear
  for later instruction x of this thread, in order:
    if class(x) in stall: hold x (and everything behind it)
    else:                 issue x

The thread keeps issuing until it reaches an instruction in a held class, so other units keep running.

Rules

rulewhy
Use STALLWAIT, not NOPs, to order one unit after another.It is the only reliable ordering between units. NOPs are not.

Timing

casecost
condition already clearabout 2 cycles (a NOP is 1)probed
second STALLWAIT behind a firstdoes not start until the first wait has clearedprobed

Waits serialise. An instruction behind an already-clear STALLWAIT took about 5680 cycles, because the STALLWAIT before it was waiting on a busy mover probed. Don't stack a cheap wait behind an expensive one you didn't mean to block on.

Arguments

namebitsdescription

opcode 0x26latency 51 cycle per fidelity phase

Matrix multiply-accumulate: Dst[8 x 16] += SrcB[8 x 16] @ SrcA[16 x 16]. A 32 x 32 tile product is a sequence of these.

It always accumulates: ZEROACC the block first for a plain product.

Encoding

Arguments

namebitsdescription
release23:22Src banks to release afterwards: 1 SrcA, 2 SrcB, 3 both.

Rows

There is no Src row operand; both come from the RWCs.

a  = RWC.SrcA & 0x30                      # 16 SrcA rows
b  = RWC.SrcB & 0x38                      # 8 SrcB rows  (single_row=1: RWC.SrcB & 0x3f)
d  = (dst + THREAD.dst_offset + RWC.Dst) & ~7
ph = (RWC.Fidelity + THREAD.fidelity_phase) & 3   # fidelity phase, wraps mod 4
for r in range(8):                        # single_row=1: SrcB[b] every r; only r in (0, 2, 4, 6) written
  Dst[d+r][:] += part_b(SrcB[b+r], ph) @ part_a(SrcA[a:a+16], ph)   # [16] @ [16 x 16]
apply(addr_mod)                           # usually steps the fidelity phase

Fidelity

Each instruction multiplies at most 5 bits of SrcA by 7 bits of SrcB, chosen by the fidelity phase: bit 0 picks the SrcA part, bit 1 the SrcB part. One pass per phase, 1 cycle each; sum the phases into the same Dst block.

RWC.Fidelity + THREAD.fidelity_phase wraps mod 4, and the result is bit-exact against the matching phase probed (e.g. fidelity_phase=3 with RWC.Fidelity=1 runs phase 0).

Error: maximum absolute error on random BF16 data in ±4. The exact high/low bit split (5 = implicit 1 + 4 mantissa bits, 7 = implicit 1 + 6) follows tt-isa-documentation's SrcAFidelityBits / SrcBFidelityBits.

SFPU

SFPU overview

The SFPU is a 32-lane, 32-bit vector unit working on LRegs. Measured on Blackhole A0 card 1.

Registers and lanes

  • An LReg holds 32 lanes of 32 bits: 4 rows of 8, covering the even or the odd columns of 4 consecutive Dst rows (see LReg).
  • Register operands (a, b, c, src, dest, lreg) take isa.LReg numbers.
  • Results are written only to L0..L7, and only in enabled lanes: a lane is enabled unless predication is on (SFPENCC) and its condition flag is clear.
  • A destination of 12..15 does not execute the instruction: it records the instruction word as SFPLOADMACRO template (destination - 12) instead. SFPCONFIG and SFPLOADMACRO are the exceptions.

  wait(slot_free[s])                    # the consumer released this slot
  issue_read(page[i], l1=slot[s], tid=RD_TID(s), cap=cap)   # paced on OUTSTANDING
  if i >= S - 1:                        # publish the oldest slot once its read has landed
    o = (i - S + 1) % S
    while read32(OUTSTANDING(RD_TID(o))): pass
    publish(o)
# drain and publish the last S-1 slots the same way

for i in range(n):                      # writer
  s = i % S
  wait(published[s])
  issue_write(out[i], l1=slot[s], tid=WR_TID(s), cap=cap)
  while read32(OUTGOING(WR_TID(s))): pass   # data has left L1: release the slot to the reader
  release(s)
while any(read32(OUTSTANDING(WR_TID(s))) for s in range(S)): pass   # all acks: output visible

blackhole-py fw/dma.c uses this shape with one TID per staging slot and DMA_CAP = 32.
