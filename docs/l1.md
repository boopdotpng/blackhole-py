# Worker L1 memory map

`fw/consts.py` is the executable source of truth for this map. All ranges below
are half-open: the end address is not part of the region.

| Region | Start | End | Size |
|---|---:|---:|---:|
| Boot jump | `0x00000` | `0x00004` | 4 B |
| Fixed firmware control | `0x00068` | `0x00374` | sparse |
| Architectural zero region | `0x032E0` | `0x034E0` | 512 B |
| BRISC firmware | `0x03840` | `0x03EB0` | 1,648 B |
| NCRISC firmware | `0x03EB0` | `0x03F88` | 216 B |
| TRISC0 firmware | `0x03F88` | `0x04050` | 200 B |
| TRISC1 firmware | `0x04050` | `0x04118` | 200 B |
| TRISC2 firmware | `0x04118` | `0x041E0` | 200 B |
| Parameter words | `0x04200` | `0x05100` | 3.75 KiB |
| BRISC worker | `0x05100` | `0x0F000` | 39.75 KiB |
| NCRISC worker | `0x0F000` | `0x18F00` | 39.75 KiB |
| TRISC0 worker | `0x18F00` | `0x22E00` | 39.75 KiB |
| TRISC1 worker | `0x22E00` | `0x2CD00` | 39.75 KiB |
| TRISC2 worker | `0x2CD00` | `0x36C00` | 39.75 KiB |
| Data buffers | `0x37000` | `0x180000` | 1,316 KiB |

The 1 KiB gap between worker text and data buffers is intentional growth and
alignment room. Circular buffers must be wholly contained in the data-buffer
region. RISC-local RAM at `0xFFB00000` is a separate address space described by
`LocalMemory` in `asm.py`; it does not consume worker L1.
