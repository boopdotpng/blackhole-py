# Archived ttrv design history

Superseded by [the consolidated specification](../../ttrv_spec.md).
These files preserve the drafts and review history, including superseded proposals.
Their old syntax, hardware assumptions and links to removed fixtures are not current contracts.

- `kernel-language-v1.md`: earlier language design.
- `ttrv_spec_new.md` and `.bak`: the source draft and backup before consolidation.
- `ttrv_spec_additions.md`: Fable's proposed additions.
- `ttrv_review.md`, `ttrv_language_contract.md`, `ttrv_v1_followup.md`: audit and design discussion.
- `ttrv_pack_unpack.md.bak`: historical measurement backup; current measurements remain above.
